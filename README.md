<h1>Internet Relay Chat (IRC)</h1>
<h3>С++ server IRC. With following features:</h3>
<li>user authentication</li>
<li>create/join channels</li>
<li>send/receive messages in channel</li>
<li>send/receive private messages</li>
<li>channel operator with ability to kick/invite users, change channel topic and more</li>
